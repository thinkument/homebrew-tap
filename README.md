# Thinkument Homebrew Tap

Official sovereign Homebrew tap for installing the **Thinkument** cognitive state machine CLI on macOS and Linux.

## Installation

```bash
brew tap thinkument/tap
brew install thinkument
```

## Verification

Confirm installation and run the zero-overhead local cognitive studio daemon ($0.00 / offline):

```bash
thinkument --version
thinkument dev
```

## Upgrade

```bash
brew update
brew upgrade thinkument
```
